## Projects

### BizNode — Knowledge-Graph Investment Insight Workspace

`2026.06 – 2026.09` · 2026 Hanium Dream-Up · AI / Data

[Organization](https://github.com/Biz-Node)

BizNode is a system that collects and preprocesses corporate disclosure data, then uses a knowledge graph and search agents to provide investment insights about relationships between companies.

- Implemented OpenDART data collection, XML parsing, preprocessing, and Neo4j ingestion
- Built a search layer including entity resolution and query routing
- Separated relationship search from semantic search and assembled results with RRF-based ranking
- Improved Korean company-name extraction and workspace-aware search
- Implemented `/retrieve` and `/ask` APIs with evidence, citations, and an agent workflow
- Added search evaluation, grounding checks, observability, and regression tests

`Python` `FastAPI` `LangGraph` `Neo4j` `PostgreSQL` `ChromaDB`

### Ban-Olim — Reading and Learning Platform

`2026.02 – 2026.06` · Capstone Project

[Organization](https://github.com/Ban-Olim)

Ban-Olim is an educational platform that supports sentence comprehension and learning for children with borderline intellectual functioning. I worked across the backend, AI service, and infrastructure so that the complete user flow could work reliably.

- Connected Spring Boot learning APIs with a FastAPI AI service
- Implemented sentence decomposition, problem generation, and LLM response validation
- Built an education data pipeline using PostgreSQL
- Integrated ElevenLabs TTS and AWS S3 audio storage
- Configured deployment with Docker Compose, Nginx, HTTPS, and GitHub Actions
- Managed CI/CD workflows and service-specific environment configuration

`Java` `Spring Boot` `JPA` `FastAPI` `PostgreSQL` `AWS` `Docker` `Nginx` `GitHub Actions`

### Jibijoa — Natural-Language Panel Search Engine

`2025.10 – 2025.11` · Pre-Capstone Project

[Repository](https://github.com/capstone-Jibijoa/backend) · [Personal Mirror](https://github.com/yyunseo/backend)

Jibijoa is a search and analysis system for panel and survey data. It interprets natural-language questions and combines structured filtering with semantic search.

- Built LLM-based natural-language query parsing and semantic routing
- Combined PostgreSQL candidate filtering, Qdrant vector search, and reranking
- Added fuzzy matching and negative-condition filtering
- Implemented multi-table search and duplicate-result removal
- Generated statistics and LLM-based insights from search results

`Python` `FastAPI` `PostgreSQL` `Qdrant` `LangChain` `Claude`

**Build with responsibility.**

I connect implementation with API contracts, data flows, deployment, logs, and tests so that the result can be verified and maintained.

**Stay close to the user.**

I define problems from the user's needs and consider whether the technology actually produces a useful outcome.
